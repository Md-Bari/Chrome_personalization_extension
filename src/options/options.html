Privacy Guarantee

🛡️
Zero External Communications

Privacy Mask does not connect to any servers, backends, or analytics platforms. All computations occur strictly inside your browser sandbox.

🔐
Web Crypto SHA-256 Fingerprints

Sensitive text content is never stored in plaintext when generating selectors; cryptographic one-way hashes are used locally.

💾
Local Storage Only

Rules and preferences are stored exclusively inside Chrome's sandboxed local extension storage (chrome.storage.local).
